# gender-pay-gap-analysis
Python-based gender pay gap analysis using real-world data

## Project over view
This projectanalyzes gender based wage differences using Python to identify pay disparities across industries and occupations.

## Tools & Technologies
- Python
- pandas
- Numpy
- Matplotlib
- Jupyter Notebook

## Dataset
This project analyzes data from the 2024-2025 reporting period to assess the extent of the gender pay gap across UK industries.

## Key Analyses
- Data cleaning and preprocessing
- Exploratory data analysis
- Statistical comparisons by gender
- Data visualization

## Results
- Descriptive statistics revealed an average gender pay gap of 12%, with a standard deviation of 14.58% and some extreme outliers (-549.7% and 100%).
- One-sample t-test result (T = 87.229, p < 0.00001), since this P value less than 0.1, this confirm that the mean gender pay gap is statistically significant difference in the avarage hourly pay betweenmale and female employees across UK companies.
- Top 10 SIC codes analysis accurately ranked industries by mean pay gap, with highest being SIC code 93120 at 58.08%
- Correclation between DiffMeanHourlyPercent and FemaleUpperMiddleQuartile was very week (r=0.044), indicating minimal linear association between pay gaps and female representation in upper-middle quartiles.

## Insights
Identifying specific industries with the largest pay gaps can help policymakers, advocacy groups, and employers prioritize targeted gender equality initiatives.
